# Project Overview

# Checkout Fields for WooCommerce

## Status
Working Title

## Vision
Build a modern, lightweight WooCommerce plugin that allows store owners to create custom checkout fields supporting both Classic Checkout and Block Checkout from the first release.

## Goals
- WordPress.org Lite version first
- Shared architecture for Lite and Pro
- Production-quality code
- Modern PHP 8.2+
- WooCommerce 9+
- WordPress 6.7+
